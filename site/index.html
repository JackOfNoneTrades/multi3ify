multi3ify

All the regular Prism versions. Minecraft 1.7.10 with lwjgl3ify, ready to launch.

A Prism-compatible metadata feed, updated automatically.

./v1/

Set up once

  1. In Prism, open Settings → APIs → Services → Metadata Server and paste the URL above.
  2. Create an instance using 1.7.10-lwjgl3ify. Leave the Mod Loader selection at None: its matching Forge and lwjgl3ify components are installed automatically.
  3. Install UniMixins (the combined jar, version 0.1.23 or newer) in the instance’s mods folder.
  4. Launch. Keep Prism’s automatic Java selection and download enabled so it can supply a compatible Java runtime.

The launcher profile handles the libraries and Java arguments. A small helper downloads and verifies lwjgl3ify before the game starts. Existing lwjgl3ify jars are backed up automatically; UniMixins and other mods are left in place.

Updates without moving jars

The New Instance dialog shows one Minecraft profile. After creating it, choose individual lwjgl3ify releases in the instance’s Version tab:

Open Edit Instance → Version → lwjgl3ify → Change version to update, pin a release, or roll back an installed instance. Choose latest for automatic stable updates, or a numbered release to stay on that version. The next launch installs the selected jar automatically.

New releases are checked every six hours. Restart Prism and reopen the instance’s Version tab if its metadata is cached. Only the lwjgl3ify picker lists mod releases; Minecraft and Forge each have one extra choice.

Add to an existing 1.7.10 instance

Set the metadata URL above, then open Edit Instance → Version → Minecraft → Change version and choose 1.7.10-lwjgl3ify. Prism switches the ordinary Forge component and adds lwjgl3ify in place. Your worlds, mods, and configuration stay in the same instance. Install UniMixins if needed and launch.

Change the Minecraft row to convert an ordinary instance. Changing only Forge leaves the old LWJGL 2 libraries installed, which conflict with lwjgl3ify’s LWJGL 3 libraries. If a previous attempt crashed mentioning PointerBuffer or CustomBuffer, complete the Minecraft selection above.

Keep automatic Java selection/download enabled and clear any forced Java 8 override. Existing local Minecraft/Forge or manual lwjgl3ify component patches need to be reverted or removed first.

Already using multi3ify?

Restart Prism and open the instance’s Version tab. The old 10.13.4.1614-lwjgl3ify-latest Forge entry automatically adds the new lwjgl3ify row. Older numbered Forge entries keep working and stay pinned. To use the new picker with one, change Forge to 10.13.4.1614-lwjgl3ify-latest, then choose your desired release in the lwjgl3ify row before launching.

This is a separate Minecraft entry so regular 1.7.10 keeps its original Java and LWJGL requirements. The integrated mod browser automatically searches for Minecraft 1.7.10. Forks need custom metadata, component dependencies, JVM arguments, and Java management support.
