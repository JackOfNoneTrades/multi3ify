All the regular Prism versions. Minecraft 1.7.10 with lwjgl3ify, ready to launch.

A Prism-compatible metadata feed, updated automatically.

./v1/

Set up once

  1. In Prism, open Settings → APIs → Services → Metadata Server and paste the URL above.
  2. Create an instance using 1.7.10-lwjgl3ify. Its matching Forge version is installed automatically.
  3. Install UniMixins (the combined jar, version 0.1.23 or newer) in the instance’s mods folder.
  4. Launch. Keep Prism’s automatic Java selection and download enabled so it can supply a compatible Java runtime.

The launcher profile handles the libraries and Java arguments. A small helper downloads and verifies lwjgl3ify before the game starts. Existing lwjgl3ify jars are backed up automatically; UniMixins and other mods are left in place.

Updates without moving jars

The default 10.13.4.1614-lwjgl3ify-latest Forge option follows stable releases when Prism refreshes its metadata. Restart Prism if its version list is cached.

To pin a release or roll back, open Edit Instance → Version → Forge → Change version and choose a numbered 10.13.4.1614-lwjgl3ify-… release. The next launch installs it automatically.

This is a separate Minecraft entry so regular 1.7.10 keeps its original Java and LWJGL requirements. The integrated mod browser automatically searches for Minecraft 1.7.10. Forks need custom metadata, component dependencies, JVM arguments, and Java management support.
